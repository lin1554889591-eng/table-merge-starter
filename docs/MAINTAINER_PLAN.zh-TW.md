# 接手後的維護計畫

以下是建議工作目標，依你的時間調整；不是贊助資格或保證通過的門檻。

| 階段 | 做一件具體的事 | 留下真實紀錄 |
|---|---|---|
| 熟悉工具 | 用虛構資料驗證聯集、交集、去重、加總及匯出 | 預期結果與實際結果 |
| 開放試用 | 邀願意的人完成一次表格合併 | 經同意的回饋與遇到的問題 |
| 修正問題 | 在 Issues 記錄、重現並修好一個問題 | 問題、修改及驗證的連結 |
| 持續維護 | 更新說明與 CHANGELOG，發布下一版 | 日期、版本與改善原因 |

只記錄實際完成的工作。有人試用才計入人數，沒有統計就寫「未統計」。不要把示範資料筆數當作使用者數，也不需要刻意湊提交次數。

AI 可以協助解釋及修改；你負責確認需求、看懂改動、檢查結果與回覆問題。先把目前功能做可靠，再依回饋決定下一項功能。

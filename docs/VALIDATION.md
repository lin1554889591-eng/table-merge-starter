# 第一版的驗證範圍

資料處理測試位於 `tests/`，可在 Node.js 20 以上執行 `npm test`。一般使用者直接開啟網站或 `dist/index.html` 即可，不需要安裝 Node.js。

- 核心測試：CSV 引號與換行、欄名檢查、資料來源、欄位聯集／交集、保留與移除重複、數字加總、匯出保護。
- 檔案整合測試：真實 XLSX 寫入後讀回、選擇工作表、文字編號、數值、公式結果、範圍限制。
- 本次執行環境沒有可用的瀏覽器視覺驗證能力；介面採響應式排版，仍需在實際手機／電腦瀏覽器確認選檔、下載與顯示。

維護者第一次操作時，依 `examples/README.md` 的預期結果核對。這些是功能驗證資料，不是外部使用者數據。
